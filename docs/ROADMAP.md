# Product notes for future work

Preserve the worthwhile ideas: small command palette UX, strict local input parsing, bounded visible fields, source-test versus installed-test language, and human review with reproducible receipts.

Planned gates:
1. Recover original owner-accepted source receipt schema and permitted integration boundaries.
2. Validate schema compatibility with actual owner source, not invented examples.
3. Run in an isolated native VS Code Insiders extension host.
4. Inspect errors, typography and keyboard navigation in real screenshots.
5. Build a reproducible VSIX; verify installation, load, rollback and checksums.
6. Obtain separate owner approval for releases, showcases and external connections.

No automatic code execution, data harvesting, credential storage, background scheduling, or private-media imports.
